# Week 1 - 파이썬 기초 및 응용

## 학습 핵심 키워드
- **컴퓨터 언어와 인터프리터 모델**: 소스코드 실행 흐름, 런타임, 에러 해석
- **개발 환경 세팅**: Python 설치, 가상환경(venv), 패키지 의존성 분리
- **변수/조건문/주석**: 상태 저장, 분기 제어, 의도 전달
- **입출력**: `input()`, `print()`, 파일 입출력
- **반복문**: `for`, `while`, `break`, `continue`
- **리스트**: 순차 데이터 저장, 필터링, 정렬, 집계
- **함수/재귀함수**: 책임 분리, 재사용성, 종료조건 설계
- **순서도 기반 설계**: 로직을 시각적으로 분해 후 구현
- **모듈/패키지 구조화**: 단일 파일에서 다중 모듈로 확장
- **타입 힌트**: 협업에서 인터페이스 명확화, 정적 분석 보조
- **예외 처리**: 입력/파일/도메인 오류에 대한 방어적 코딩
- **컴프리헨션**: 선언적 데이터 변환
- **이터레이터/제너레이터**: 지연 평가를 통한 메모리 절감
- **비동기**: I/O 대기 구간 최적화 기본 개념
- **고차 함수**: 함수를 인자로 전달해 정책 분리
