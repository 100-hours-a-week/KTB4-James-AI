# DeepDive 04 - Checked 예외가 없는 파이썬의 예외 처리 설계

## 배경
- 파이썬은 Java의 checked exception 체계가 없어 호출부 강제가 없다.
- 따라서 "문서화 + 경계 검증 + 일관된 예외 계층"이 중요하다.

## 과제1 예외 처리 리뷰
- `EOFError`, `KeyboardInterrupt`를 정상 종료 흐름으로 처리
- `ValueError`를 입력 파싱 경계에서 국소 처리
- 범위 검증(`index < 1 or index > len(tasks)`)으로 도메인 오류 사전 차단

## 안정성을 높이는 설계 원칙
1. 예외를 넓게 잡지 말고(예: `except Exception`) 구체 타입으로 한정
2. I/O 경계, 사용자 입력 경계에서만 방어적으로 처리
3. 예외를 삼키지 말고 사용자/로그에 맥락 제공

## 남용 시 문제
- 과도한 try/except는 정상 흐름 가독성을 해침
- 빈번한 예외 발생을 제어 흐름으로 사용하면 성능 저하 가능
