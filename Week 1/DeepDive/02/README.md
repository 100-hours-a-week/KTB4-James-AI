# DeepDive 02 - 과제1의 조건문/반복문 실용 예제 해설

## 발췌 예제
- 무한 루프: 메뉴를 반복 제공하여 사용자 작업을 이어감
- 분기문: 입력값(1~4)에 따라 기능 라우팅
- 반복 출력: `enumerate`로 할 일 번호와 상태 표시

## 동작 방식
1. `while True` 진입
2. 사용자 선택을 문자열로 입력
3. `if/elif`로 기능 분기
4. 오류 입력 시 안내 후 루프 복귀
5. 종료 선택 시 `break`

## 실용성
- 상태 기반 콘솔 앱의 표준 패턴
- 입력 에러를 회복 가능한 흐름으로 처리해 UX 개선
