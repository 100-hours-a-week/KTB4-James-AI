# DeepDive 01 - 파이썬이 초급자에게 적합한 이유와 한계

## 핵심 결론
- 적합한 이유: 문법 간결성, 풍부한 학습자료, REPL 기반 빠른 피드백, 다양한 도메인 확장성
- 한계점: 실행 성능, 배포/의존성 복잡도, 동적 타이핑으로 인한 런타임 오류 가능성

## 비교 관점
- vs C/C++: 입문 난이도는 파이썬 우세, 성능/메모리 제어는 C/C++ 우세
- vs Java: 초반 문법 장벽은 파이썬이 낮음, 대규모 정적 타입 생태계는 Java 우세
- vs JavaScript: 웹 친화성은 JS 우세, 데이터/자동화 생태계는 파이썬 우세

## 학습 전략 제안
1. 파이썬으로 알고리즘/자동화 기본기 확보
2. 타입 힌트/테스트 습관으로 동적 타이핑 리스크 완화
3. 성능 병목만 선택적으로 저수준 언어/도구와 혼합
