# Week 1 학습/과제/딥다이브 실행 프롬프트 (정제본)

## 목표
1주차 **파이썬 기초 및 응용** 수업 내용을 기준으로, 학습 정리/과제 구현/심층 탐구 결과를 재현 가능한 형태로 문서화한다.

## 산출물 구조
- `Week 1/README.md`: 1주차 핵심 학습 키워드 정리
- `Week 1/Assignment/README.md`: 과제 목차
- `Week 1/Assignment/01/`: CLI 프로그램(동기 버전) + 설계/예외처리 문서
- `Week 1/Assignment/02/`: 01 리팩토링(패키지/설치형/타입힌트/이터레이터·제너레이터 반영)
- `Week 1/DeepDive/README.md`: 딥다이브 목차
- `Week 1/DeepDive/01~05/README.md`: 각 주제별 보고서
- `Week 1/DeepDive/03/boilerplate/`: 대규모 협업 가정 타입힌트 관찰용 보일러플레이트
- `Week 1/DeepDive/05/`: 실험 쉘 스크립트 + 모니터링 CLI

## Week 1 수업 범위 반영 체크리스트
### 파이썬 기초
- 컴퓨터 언어
- 개발 환경 세팅
- 변수, 조건문, 주석
- 입력과 출력
- 반복문
- 리스트
- 함수, 재귀함수
- 순서도

### 파이썬 응용
- 가상환경
- 모듈, 패키지
- 타입 힌트
- 예외 처리
- 컴프리헨션
- 이터레이터, 제네레이터
- 비동기
- 고차 함수

## 과제 수행 기준
### 과제 1
- 콘솔 기반 CLI 프로그램 구현 (`input`, `print` 활용)
- **조건문/반복문 설계**를 코드 이전에 문서로 명시
- 예외처리 전략(입력 검증, 경계값, EOF/KeyboardInterrupt, 파일 I/O) 설명

### 과제 2
- 과제1 결과물을 패키지 구조로 리팩토링
- 설치/실행 가능 형태로 구성
- 타입 힌트 도입 이유와 한계 문서화
- 이터레이터·제너레이터를 도입해 대용량 처리 시 메모리 효율 개선

## 딥다이브 수행 기준
1. 파이썬 vs 타 언어(초급자 관점 강점/한계)
2. 과제1 코드의 조건문/반복문 실용 예제 해설
3. 과제2 리팩토링의 타입 힌트 도입 효과/한계 + 보일러플레이트 구현
4. Checked 예외 부재 환경에서 안정적 예외처리 설계
5. 이터레이터·제너레이터 효율성 시나리오 + 설치/실험/수치화 모니터링 도구

## 품질 기준
- 실행 방법, 기능, 예시, 설계 의도, 트레이드오프를 문서화
- 재현 가능한 커맨드 제공
- "무엇을 만들었는가"보다 "왜 이렇게 설계했는가"가 드러나도록 기록
