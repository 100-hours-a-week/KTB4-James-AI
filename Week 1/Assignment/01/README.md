# Assignment 01 - 동기 CLI 프로그램

## 프로그램 개요
- 이름: `cli_study_tracker.py`
- 목적: 주차 학습 할 일을 콘솔에서 추가/조회/완료 처리
- 입력/출력: `input()`, `print()` 기반

## 설계 방향(조건문/반복문 중심)
1. **무한 루프(`while True`)로 메뉴 지속 제공**
2. **조건문(`if/elif`)으로 메뉴 분기**
3. **예외 상황 우선 처리(Guard Clause)**
   - 빈 제목
   - 빈 목록에서 완료 처리 시도
   - 번호 파싱 실패, 범위 초과
4. 목록 출력은 `for + enumerate` 사용

## 간단 순서도
1. 메뉴 출력
2. 사용자 입력
3. 1/2/3/4 분기
4. 처리 후 다시 메뉴
5. 종료 선택 시 break

## 예외 처리 설계
- `EOFError`, `KeyboardInterrupt`: 사용자 입력 중단 시 정상 종료
- `ValueError`: 완료 번호 정수 변환 실패 시 안내 후 복귀
- 도메인 검증: 인덱스 범위 점검, 빈 문자열 입력 차단

## 실행 방법
```bash
cd "Week 1/Assignment/01"
python3 cli_study_tracker.py
```

## 기능
- 할 일 추가
- 목록 보기
- 완료 처리
- 종료

## 사용 예시
```text
=== Study Tracker ===
1) 할 일 추가
2) 할 일 목록
3) 완료 처리
4) 종료
메뉴 번호 선택: 1
할 일 제목: 반복문 복습
할 일이 추가되었습니다.
```
